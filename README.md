# OCR PDF Converter

macOS app for batch converting PDFs to Word (.docx) or Plain Text (.txt) using OCR.

## Requirements

```bash
brew install tesseract poppler
```

## Setup

```bash
bash build_cli_app.sh
```

Then launch from Applications folder.
